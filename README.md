# PolyHop (web app)

The built version of **PolyHop**, a browser editor and engine for low-poly / pixel-texture 3D platformers.
It runs entirely in your browser: nothing is uploaded, projects are saved to files on your computer.

This repository only holds the build, published with GitHub Pages. The source is at
<https://github.com/stihilus/PolyHop>.
